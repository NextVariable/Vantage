# Vantage 1.0 Beta 候选验收

Vantage 是按需研究和机会发现 Skill。默认研究最近 30 天，可调整时间窗口。行业、需求、竞争属基础场景，机会假设仅按明确请求生成。

候选分支为 `release/vantage-1.0-beta`，版本 `1.0.0b1`。保留了远端审计头 `e59f4f1a0e48f1f68e02bd83a32c049717a61bb1` 和审计代码 `a737b6f`。本地已有的 TRAE 后续提交都在候选分支祖先中。代码验收提交为 `b59a5e9507034bdd7b5e65b5b71e373d2e77d71b`。

## 关闭问题

- **STDIO。** 支持关联的 Host 回传准确的请求 ID。迟到、重复、乱序帧按 ID 丢弃，未匹配的帧不能自行启用关联。旧 Host 超时后停止复用流。真实管道回归覆盖超时后 FACT 的实际派发和收包。历史同轮干净提交 `6da52f7` 的行业案例里，第三个 contradiction 请求超时，下一条 `fact_synthesis` 回复 ID 匹配并被接受，生成三条带标注的 FACT。这一实现与最终代码相同。另一次受控 Codex 探针也派发了 FACT，宿主返回时已经超过请求 deadline；探针按失败记录。 [协议回归](../tests/unit/test_host_recovery.py)
- **FACT。** 每条显示主张和每个 Evidence ID 绑定到来源同一字段中的原文摘录。覆盖缺口、无关 ID、标题与正文拼接、不同草稿共享 ID 以及供应商冒充独立验证均有拒绝或降级。宿主语义校验发现冲突或无关后，该陈述不能进入推论。未完成语义校验的材料逐条标明为引文、归因或待核实。语义校验本身仍是 Host 对引文的判断，独立实测须另有原始证据。 [事实回归](../tests/unit/insights/test_evidence_support_contract.py)
- **排序。** 混合已评估与未评估的信号在同一组共同可用因子上排序，几何加权方式保留；弱信号判断仍使用单项真正测得的相关性。冻结账本中的 32 条记录复放时，所选两条证据的评分为 0.61306 与 0.52389，交换输入顺序后顺序不变，覆盖权重均为 0.65。原文引用探针通过，跨记录挪用同一引文的探针被拒绝。这是冻结证据回归。 [排序回归](../tests/unit/intelligence/test_signals.py)

## 实际运行范围

Codex CLI 使用现有 ChatGPT 登录，模型 `gpt-6.1-sol`，使用默认 Skill 的 `host_stdio:build_model` 与 hybrid 公开来源配置。按 2026-11-24 08:15 UTC 固定截止，每题至多两轮检索。研究与综合引擎预算合计 345 秒，运行器 355 秒后终止引擎，记录期可另含回收 Host 所需时间。每例给予 6 次公开网页操作的指令预算，并独立记录实际工具事件。候选复跑不把提供商凭据传给子进程。账单金额未知。

```sh
python scripts/run_real_benchmark.py --as-of 2026-11-24T08:15:00Z \
  --catalog evals/beta-acceptance.json --output runs/rc/beta-reproduction \
  --seconds 355 --max-rounds 2 --workers 2 --web-budget 6
```

原始计划、按序号记录的请求/回复、来源状态、账本、简报和运行凭证存于本地忽略目录。公开样例只包含实际得到的研究结果概要和独立出处复查。

## 发布决定

**BETA_BLOCKED。** 最小剩余工作是让竞争研究在部分来源失败或评估超时时至少从已核实的双边来源形成具体对照，剔除只提及产品名的材料，并保留一手反馈缺口。随后在干净提交上仅重验竞争这一门。当前候选已经推送，等待发布门槛满足再请求发布授权。

Beta 之后的非阻断项为扩充已观测来源限流的提示、合并重复的来源限制说明，以及校准通用网页路由的一手发布者分级。保留原研究产品范围和现有 Host。
